# Draft: 收藏域名功能 (Favorite Domains)

## 项目背景
- Next.js 16 App Router 项目
- WHOIS 域名查询工具，支持批量查询
- 已有 shadcn/ui 组件库、i18n 国际化
- 查询结果展示支持卡片/列表视图、排序

## 用户需求 (初步)
1. 查询后支持收藏域名到收藏列表
2. 增加收藏域名管理页面
3. 支持一键检查收藏域名
4. 域名有"全部域名"和"分组"概念
5. 在分组中只会检查分组的域名
6. 收藏的域名本地存储 (localStorage)

## 已确认决策
- **分组管理方式**: 在收藏管理页面内分组（类似书签文件夹）
- **收藏交互方式**: 每结果卡片添加收藏按钮 + 批量全选收藏
- **管理页面布局**: 左侧分组树 + 右侧域名列表
- **管理页面功能**: 完整功能（CRUD分组、拖拽排序、导入导出、备注、搜索过滤、批量移除）
- **页面入口**: 独立路由 `/favorites`，导航栏添加链接
- **一键检查交互**: 从收藏页点击检查 → 跳转首页并自动填充域名开始查询
- **测试策略**: 无需单元测试，Agent QA 验证
- **存储方式**: localStorage

## 范围边界
- IN: localStorage存储、收藏按钮、批量收藏、/favorites页面、分组管理、拖拽、备注、搜索过滤、导入导出JSON、一键检查、多语言
- OUT: 后端存储、用户认证、域名自动监控/提醒、数据库、修改现有API

## 技术方案要点
- 使用 localStorage 键值存储收藏数据
- 数据结构：分组列表 + 域名收藏列表
- 新页面 /favorites 作为独立路由
- 一键检查通过URL参数传递域名到首页
